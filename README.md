## 一、它能做到什么

| 能力 | 说明 |
| --- | --- |
| **从零装好环境** | 首次启动自动下载安装 XXMI Launcher、XXMI Libraries、EFMI 等组件（带校验），装完写好配置 |
| **Mod 库管理** | 把压缩包（`.zip` / `.7z` / `.rar`）拖到页面任意处即可导入：自动解压、尝试识别角色（中文名、社区昵称、英文代号、**拼音**都认），认不出就弹窗让你选（下拉已按"最可能的角色"预选）。**大封面卡片**一眼能认出是哪件衣服；每张卡片自带启用开关，卡片「⋯」里可随时**更换归属 / 修复 / 回滚 / 打开目录 / 移出库**。**同一个包重复导入不会在库里留下两份**（比内容指纹） |
| **自动备份你的 Mod** | 程序旁边会有一个 **Mod 备份文件夹**：只要库里出现**新导入的 Mod**，就自动把它**整份复制**进去（不压缩）。**只增不减** —— 程序从不删除、不覆盖里面的任何文件（想清就自己删）。设置页能看到数量与占用，也能一键打开 |
| **同角色互斥** | 同一个角色只保留一个 Mod —— 同时加载两个同角色 Mod 常把游戏搞崩（确认**不冲突**的组合，可在 Mod 库页用「强行关闭角色 Mod 互斥」放行） |
| **一键启动** | 维护注入库、补齐缺失组件、跑完整初始化自检，然后拉起 XXMI |
| **插件开关** | DLSS5、第一人称、服装 Mod、乳摇、摆姿都能单独开关（靠移动文件实现，可逆）；「依赖清空并重新下载」可在组件装坏时一键清空重来 |
| **Mod 下载** | Mod 库页点「下载 Mod」，**粘贴直链**（一行一个）→ **并行下载**（内部按需分块、自动换线路、断点续传）→ **能解压的自动解压进库**并识别角色；不能解压的留在临时目录并告诉你路径。**香蕉网（GameBanana）链接直接支持**：粘页面地址就自动换成真实文件直链、带出封面与作者版本信息；访问不上（需要代理的常见情况）会提示检查 VPN |
| **游戏内统一面板** | 进游戏按 `Home` → **ModeController** 页：按角色 / Mod 分栏，**每一项就是一个按钮** —— 点一下等于按一次这个 Mod 自己的切档键。多个 Mod 抢同一个键时，从面板点就不会按错；面板还能调**界面大小**、一键重置面板布局 |
| **启动前风险确认** | 拉起游戏之前先查"这套 Mod 会不会崩"（资源冲突 + 过去崩过的组合），有风险就说清是什么冲突，由你决定要不要继续 |
| **崩溃归因** | 崩了会区分"Mod 资源冲突"与其它原因：是皮肤冲突的话，弹窗里能**一组一个下拉框**选要保留的 Mod、一键关掉其余的（只改勾选，不动你的文件）；同时生成带完整现场的诊断包，直接发 issue 或 QQ 群即可 |
| **Mod 修复 / 回滚** | 游戏版本更新后老 Mod 常需适配，在 Mod 卡片上就能一键修；**改前自动整份备份、可一键回滚** |
| **游戏目录净化 / 还原** | 把第三方注入物**先备份再移走**，随时一键还原；被移走的系统模块会自动补回 |
| **更新** | 程序本体与各组件都能检查、更新；进度条的分母就是实际要处理的项数 |
| **文件被反复删除会提醒你** | 关键组件被安全软件（Windows Defender / 360 / 火绒）隔离时，启动时会告诉你**是哪个文件、该把哪个目录加入白名单** |
| **摆姿 / MMD 播放**（可选） | 集成 Endfield Poser，用它自带的页面摆姿势、放 MMD |

## 二、它是怎么工作的

一次「一键启动」做四件事：**补齐运行环境 → 维护注入库 → 跑初始化自检 → 拉起 XXMI**；你只需要在 XXMI 界面点 Start。

游戏进程里同时存在这些东西，全部由注入库决定：

```text
 唯一的一个 ReShade 底座
   ├─ DLSS5 神经渲染
   ├─ 第一人称 / 相机
   ├─ 面板汉化
   ├─ 喂帧组件（给 DLSS5 提供颜色 / 运动矢量 / 深度）
   └─ 后处理 shader
 服装 Mod 引擎（EFMI）
 乳摇注入代理
 摆姿 / MMD 注入代理（可选）
```

三条关键设计：

1. **一个游戏进程只能有一个 ReShade 底座** —— 所以本程序把 DLSS5 与第一人称合到同一个底座上，不会塞两份；这也是"两个整合包混着用必崩"的原因。
2. **不改游戏本体** —— 写进游戏目录的都是注入类文件，改动前一律先备份、随时一键还原；游戏本体、资源、存档一律不碰。
3. **不内置 Mod** —— Mod 都是你自己放进去的；程序负责解压、识别角色、同角色互斥，以及在启动前把可能崩的组合拦下来。

> 本程序**只做编排与自检**：注入交给 XXMI，插件本体一律不修改（改了也会被上游更新覆盖）。配置与数据都放在 exe 旁边，换台机器整个文件夹拷走即可。

## 三、怎么用

### 第一次使用

1. 到 [Release](https://github.com/jing-hy/EndfieldModController/releases) 下载 `EndfieldModController.exe`（同页还有一个 `assets-bundle.zip`，首次启动会自动下载）；
2. 放到**你有写权限的普通目录**再双击 —— 别放 `Program Files` 这类只读目录，也别放临时目录（程序的数据与你的 Mod 库就在 exe 旁边）；
3. 点「**一键启动**」。首次会自动装好运行环境；若提示"请再点一次"，照提示来即可（那是让 XXMI 先生成它自己的配置）。

之后进游戏就行：**DLSS5 不需要任何手动配置**，看 ReShade 面板里的「成功NR帧」涨起来就是生效了。首次启动会有一次**分步引导**，带高亮指向要点的按钮。

### 日常使用

- **Mod 库页**：把压缩包拖进来即导入；用卡片上的开关勾选（同角色自动互斥）后点「生成控制器」。
- **依赖页**：看组件是否齐备（绿=已就位 / 红=缺失）、下载速度与实时日志；缺什么点「安装缺失依赖」。
- **启动页**：大号「一键启动」+ 各插件开关 + 运行日志。
- **设置页**：注入开关、自检、组件更新、诊断包、游戏目录还原、路径与外观、维护操作等都在这里。
- **摆姿 / MMD（可选）**：游戏运行时用它自带的页面摆姿势、放 MMD。

### 游戏内统一面板

Mod 自带的按键各不相同（`←`、`Ctrl+5`、`Alt 0`…），装多了不仅容易记混，**还常常互相抢同一个键**——好几个 Mod 都用 `→`/`←`/`↓`，手按时谁被触发说不清。

所以启动页提供了一个「**Mod 快捷键锁定**」开关（默认开启）：打开后**把统一面板放进 ReShade**，进游戏按 `Home` 切到 **ModeController** 页，点某一项就等于按一次那个 Mod 自己的键。

- **不锁你的按键** —— 面板走的是"发 Mod 原键"这条路（`SendInput` 合成的按键在游戏进程里收不到，实测无效，所以改成由面板直接发那一项专属的原键）。你手按原键照常有效，面板只是多给一个遥控器。
- **不会自己关掉** —— 想连切几档就连点几下。
- 面板还能调**界面大小**（0.75×～2×，会记住）和一键**重置面板布局**（标签栏被挤出屏幕时用）。
- 面板装不上时它会说明原因（面板日志在日志页能看到）。

## 四、常见问题

**Q：DLSS5 面板显示开着，但「成功NR帧」不动？**
先看启动日志里自检有没有报错；再确认游戏内超分选的是 **DLSS**（选 FSR / XeSS 时神经渲染不会绑定）。更细的排查顺序见详细文档。

**Q：DLSS5 的开关默认是关的 / 想打开被拒绝了？**
说明你的显卡**没有 tensor core** —— DLSS5 神经渲染必须跑在 NVIDIA 自己的运行库上，需要 **RTX 20 系及以上**；GTX 10 系及以下、GTX 16 系、A 卡与 Intel 核显都不行。这类机器上它一帧也出不来，所以程序**默认帮你关掉、也不让你打开**，免得你以为装坏了去折腾（改分辨率、换驱动、重装都是白费）。

RTX 20 / 30 / 40 / 50 系都能用：程序会**按你的显卡架构自动准备对应的运行库**，不需要你做任何额外设置（40 系还可以在依赖页选装一个更贴合 Ada 的优化版，不装也照样能用）。

**Q：第一人称进去是英文？**
在它自己的面板里把语言切成中文即可，程序会记住（这个属于个人偏好，程序不会去覆盖你的选择）。若面板里中文显示不出来，多半是 ReShade 的字体被改成了不含中文的字体，把 ReShade 的字体设成中文字体、或点一次「一键启动」由程序补回默认中文字体。

**Q：游戏崩了 / 加载中闪退？**
程序会生成崩溃包并给出**归因**：如果是 Mod 资源冲突，弹窗会直接列出是哪两个 Mod，去 Mod 库关掉其中一个再启动即可；其它原因也会带上完整现场，把崩溃包发到 Issues 就能定位。

**Q：第一次点「一键启动」被提示"再点一次"？**
正常 —— XXMI 的配置要它自己跑一次才会生成，程序先替你拉起来生成，再点一次就好。

**Q：Mod 装了很多，进游戏没生效？**
先确认对应开关是开的（服装 Mod / 乳摇 / DLSS5 各自独立），再看自检结果；同一角色只会保留一个 Mod，勾选后记得点「生成控制器」。

**Q：游戏版本更新后老 Mod 失效？**
用 Mod 卡片「⋯」里的「**修复**」——它会适配资源槽位号，**改前自动备份、可一键回滚**。

**Q：自检或「修复」老是说某几个文件缺失，补上以后又缺？**
多半是**安全软件把它们隔离了**（最常见的是 DLSS5 的 NR 运行库那种大文件）。程序每次启动都会记一次"这些关键文件在不在"，**连续几次发现同一个文件不见了时**，你点「一键启动」就会先弹窗告诉你**具体是哪个文件**、并把**该加入白名单的目录**列出来；加完白名单再点一次即可，缺的文件会自动补回来。

**Q：我本来就有另一份装好 Mod 的 XXMI，想继续用它？**
可以。在设置里把 XXMI 指到你那份、把 Mod 的中转目录也指到那份，并关掉"用内置运行环境"这一项 —— 之后程序既不会下载/更新自带那份，也不会改你填的路径。想换回来就反向操作。

**Q：启动时弹的「公告」，或者点一键启动前的红色预警是什么？**
那是作者通过项目仓库下发的通知。**公告**用于发布重大信息，看完关掉就行；**异常状态预警**（例如出现大规模封号）会在你点「一键启动」时先强制停留几秒，再请你三选一：**还原配置**（关掉全部注入并清理游戏目录，随时可撤销）、保持配置但不启动、仍然启动。它只在联网时检查，拉不到就静默跳过，不影响使用。

| 方式 | 怎么用 |
| --- | --- |
| **GitHub issue** | 到 [Issues](https://github.com/jing-hy/EndfieldModController/issues) 发帖，把诊断包 zip 拖进正文 |
| **QQ 群** | 群号 **1045239747**，加群验证答案 **jing_hy**；不方便用 GitHub 就在群里发 |
