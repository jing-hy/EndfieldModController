> 用途：B 站投稿主片。全片 1:55 ~ 2:00，快节奏，无口播（或 8 句 AI 配音），
> 主体是**程序界面录屏 + 游戏内画面录屏**。本文档按「拍摄批次」组织，照着录一遍即可剪完。

## 0. 定位与取舍

| 项 | 结论 |
| --- | --- |
| 观众 | 终末地玩家：想上 DLSS5 / 第一人称 / 服装 Mod，但被环境、注入、崩溃折腾过的人 |
| 一句话主线 | **一个 exe，把 DLSS5 + 第一人称 + 服装 Mod + 物理效果 一次装好** |
| 语气 | 不吹、不教程化，像老玩家现场演示；字幕短句，一句话一个功能 |
| 必给时间（按顺序） | ① 一键装环境 ② Mod 库拖拽＋同角色互斥 ③ 一键启动与四个开关 ④ 游戏内效果对比 ⑤ 净化/还原 ⑥ 更新 ⑦ 崩溃诊断包 |

## 3. 录制技术设置

- **OBS**：1920×1080 / 60fps；码率 CQP 18~20（或 20~40 Mbps）；录 mkv，剪完再转 mp4，防崩溃丢文件。
- **捕获方式**：程序界面用「窗口捕获」（pywebview = WebView2 窗口；若黑屏改「显示器捕获」）；游戏用「游戏捕获」，不行则显示器捕获。
- **字体清晰度**：系统缩放若不是 100%，录出来的界面字会糊 —— 录制时临时切到 100% 缩放，或直接录 2560×1440 再缩到 1080p。
- **鼠标**：开光标高亮 + 点击特效（或用剪映的点击圈），录制时把鼠标移动放慢一半，剪辑再加速即可"快而不乱"。
- **环境**：关掉微信 / QQ / Steam++ / 各种通知；关掉录屏软件水印；界面统一用同一个主题（建议深色，和游戏画面更搭；加载页主色会自动跟随主题）。
- **隐私**：路径里出现 `C:\Users\<你的用户名>` 的地方打码；`D:\zmdmod\...` 这类无所谓的不用处理。
- **素材命名**：`A9_一键启动.mp4`、`B1_DLSS5对比_关.mp4` —— 直接对齐本表的编号，剪辑时不用回看。

## 4. 剪辑与节奏

- **BGM**：130~150 BPM 电子 / Glitch hop；用剪映「自动踩点」，让每个功能切换落在重拍上。B 站音乐库或剪映音乐库挑，别用有版权风险的商业曲。
- **转场**：只用 0.1~0.2 秒硬切 / 闪白，不要花哨转场；功能之间的"切换感"靠**字幕条进出 + 音效**建立。
- **变速**：下载、自检、升级这类等待画面 4~8 倍速（配合"时间流逝"的进度条运动）；操作动作 1.5~2 倍速。
- **字幕**：一行 ≤ 14 字，最多两行；不用逐字动画（拖节奏），用"整行弹出 + 卡点"；关键数字/文件名高亮。
- **音效**：点击"咔"、拖放"呼"、完成"叮"、成功"success"、警示"低沉 whoosh"。每个功能一个小音效，观众就能感知节奏。
- **配色**：字幕底色用主题色（深色主题的强调色），全片统一。
- **时长兜底**：如果 2 分钟真的塞不下，砍 A13、A11、C1，保留 A2/A4/A6/A9/B1/B5/A10——这六个是全片骨架。

## 6. 合规与注意

- 全片避免"外挂 / 修改器 / 破解 / 绕过反作弊"等词，统一说「Mod 管理器 / 整合启动器」。
- 不承诺"不会被封"，明确说「有 ToS 风险，自负」。
- 服装、物理效果的画面尺度要收着点；B 站对游戏 Mod 一般宽容，但露骨画面容易限流。
- 把「不删文件、只备份移走、可一键还原」「不碰反作弊」这两句放在画面里出现（1:18 与 1:50 各一次），这是这个项目相对"手改注入"的核心安全感。
