## 两条值得先知道的结论

1. **路径长度是硬限制**：注入框架按自身所在目录解析配置，路径一长游戏就会崩或插件静默失效。
   第三方组件请放盘符根下的短目录。
2. **标注「已废弃」的路线不要照做** —— 那些方案都已被当前路线取代，档案保留只为历史追溯。
