## 两条值得先知道的结论

1. **路径长度是硬限制**：EFMI / ReShade 按自身所在目录解析配置，路径一长游戏就会崩或插件静默失效。第三方组件请放盘符根下的短目录（见主 README 第二节）。
2. **标注「已废弃」的路线不要照做**：外部注入 `ReShade64.dll`、XXMI `Bypass`、进程内桥、3DMigoto loader、游戏目录 proxy 这些方案都已被当前路线取代，代码保留只为历史追溯。
