# 降级 NVIDIA 驱动到 580.88 —— 操作指引

> 目的：让 **EFMI 引擎**（v1.1.9 / v1.3.16）不再在 55–56 秒崩 `nvgpucomp64.dll`。
> 只有 EFMI 引擎才认识那些 Mod 用的扩展语法（`[Pool_ShapeKeys_*]`、`mode=uav`、`[Pool_*]`），
> 而"模型改形"（去衣服 / 变肥美等）正是靠这些语法实现的 —— 这是「皮肤打不上」的根因。

## 为什么是这个版本

| 证据 | 来源 |
|---|---|
| **"581.15 起的全局驱动问题，影响所有第三方 DLL；580.88 没有这个问题"** —— XXMI 维护者原话 | [SpectrumQT/XXMI-Launcher #218](https://github.com/SpectrumQT/XXMI-Launcher/issues/218) |
| **"595.97 明显比更新驱动崩得少"** | [ValveSoftware/Dota2-Gameplay #34220](https://github.com/ValveSoftware/Dota2-Gameplay/issues/34220) |
| **同一驱动 `32.0.16.1692` 在别人机器上也"启动后 35–55 秒"崩同一个模块** | [NVIDIA Dev Forum #343335](https://forums.developer.nvidia.com/t/rtx-5070-ti-nvgpucomp64-dll-exception-thrown-when-shader-uses-gl-nv-shader-sm-builtins/343335) |
| 本机实测：616.92 与 617.14 **两版都崩**，偏移随驱动变化（0x3c50b6b → 0x3c5141b） | 本机 Application 事件日志 |

**580.88 发布于 2025-07-31（WHQL）**，在问题区间（581.15+）之前。

## 下载

- 官方：<https://www.nvidia.com/en-us/drivers/details/251285/>
- 备用：<https://www.guru3d.com/download/nvidia-geforce-58088-whql-driver-download/>

选 **GeForce RTX 5080 / Windows 11 64-bit / Game Ready Driver**。

## 步骤

1. **先备份当前状态**（我们改过的配置文件）：
   ```
   D:\zmdmod\modecontroller\runtime\migoto\d3dx.ini
   D:\zmdmod\modecontroller\runtime\migoto\d3dx_user.ini
   C:\Users\Administrator\AppData\Local\NVIDIA Corporation\NVIDIA App\NvBackend\ApplicationStorage.json
   ```
2. **下载 DDU**（Display Driver Uninstaller）：<https://www.wagnardsoft.com/display-driver-uninstaller-DDU->
3. **断网**（防止 Windows Update 自动装回新驱动）。
4. **重启进安全模式**，运行 DDU → 选 **NVIDIA** → **Clean and restart**。
5. 正常启动后，**运行 580.88 安装包**：
   - 选 **自定义安装 → 执行清洁安装**
   - **不要勾** GeForce Experience / NVIDIA App（覆盖层是已知崩溃源）
   - 只装 **图形驱动程序**（PhysX/HD 音频可留可去）
6. **装完重启**。
7. **清着色器缓存**（驱动换代必须清）：
   ```
   删 %LOCALAPPDATA%\NVIDIA\DXCache 全部内容
   删 %LOCALAPPDATA%\NVIDIA\GLCache 全部内容
   删 %LOCALAPPDATA%\Low\Hypergryph\Endfield\dx11_pso_cache.bin
   删 %LOCALAPPDATA%\Low\Hypergryph\Endfield\vulkan_pso_cache.bin
   ```
8. **重连网络**，确认驱动版本：
   ```
   nvidia-smi --query-gpu=driver_version --format=csv
   ```
   应显示 **580.88**。

## 回到项目后要测什么

切换回 **EFMI 引擎路线**（这样才能支持 Mod 的扩展语法）：

| 项 | 值 |
|---|---|
| 引擎 | `runtime\migoto\d3d11.dll` = **v1.1.9**（EFMI） |
| 配置 | `runtime\migoto\d3dx.ini` = EFMI 版（`include = Core\EFMI\main.ini`） |
| 注入器 | `migoto_loader2.exe`（bootstrap 模式，`inject_order.txt = mc_bootstrap.dll`） |
| Mods | `runtime\migoto\Mods\`（保持 `_endfieldmodcontroller_managed\<角色>\<Mod>\` 结构与 `d3dx_user.ini` 键名一致） |
| ReShade | **先不开**（它与 3DMigoto 抢 hook：实测代理形态 24 秒早退、桥注入连窗口都不出）；等 Mod 先通了再谈共存 |

**判读标准**：能否撑过 **55–60 秒**（历史崩溃点）；能过就进游戏看模型。

## 如果 580.88 也不行

那就说明这条路走不通，转 **Better Endfield**（`Dr-hydra/Better-Endfield`）：
用 IL2CPP 注入替代 d3d11 劫持，自带 OptiScaler 管 DLSS，
现有 3DMigoto 格式 Mod 需转成 BEM 包（v3.3.0 支持转换）。
