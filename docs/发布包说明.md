# 发布包说明

## 生成

```bash
python scripts/package_release.py
```

产物：

```text
dist/EndfieldModController-0.1.0-portable.zip
dist/EndfieldModController-0.1.0-portable.zip.sha256
```

## 发布包内容

- `endfieldmodcontroller/`：Python 包
- `web/`：外部 UI
- `reshade_addon/`：ReShade Addon 源码
- `dist/endfieldmodcontroller.addon`：已构建的 ReShade Addon
- `scripts/`：安装、ReShade 下载、打包、自检脚本
- `docs/`：测试和架构文档
- `tests/`：单元/离线端到端测试
- `dependencies.json`：依赖清单
- `run.bat` / `run.sh`

发布包不包含：

- 用户 `library/`
- `runtime/`
- `config.json`
- 真实 Mod 内容
- 游戏目录文件

## 解压后的首次使用

Windows：

```text
scripts\install.bat
run.bat
```

首次启动后：

1. 在设置页填写 XXMI Launcher、Endfield.exe、staging Mods 路径。
2. 点击“下载 ReShade Addon”或运行：

```bash
python scripts/setup_reshade.py
```

3. 把 Mod 放进 `library/<角色>/<Mod>/`。
4. 扫描、选择、生成控制器。
5. 启动页预览并一键启动：程序会打开 XXMI Launcher，但不会自动启动游戏；请在 XXMI 里点 Start。
6. 如果游戏目录已有 ReShade（dxgi.dll + ReShade.ini），程序只写入 `endfieldmodcontroller.addon64`、`actions.tsv`、`user_ini_path.txt` 三个可回滚文件，不改名或覆盖 `dxgi.dll` / `d3d12.dll`。

## 校验

```bash
python scripts/self_check.py
```

会执行：

- 单元测试
- 离线端到端测试
- ReShade Addon 存在性检查
- 发布包完整性检查
- CLI 状态检查

## 注意

发布包只包含源代码和已构建的 ReShade Addon，不包含 ReShade64.dll；ReShade 由 `scripts/setup_reshade.py` 从官方下载并解压到 `runtime/reshade/`。
