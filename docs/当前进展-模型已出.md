## 已经查明的三件事

### 1. 用户问的「是不是同一角色打了两个 mod」→ 是的，这就是"损坏"的原因

庄方宜此前**同时存在两个 Mod**：

| 位置 | Mod |
|---|---|
| `Mods\_endfieldmodcontroller_managed\庄方宜\庄方宜-原版切换 _内附切换_by lewdlad` | lewdlad 版（9/26 生效的那个） |
| `Mods\庄方宜-定制1.4fix(alt+6) by KatTheDev` | KatTheDev 版（15 个 ini / ShapeKey×10） |

两个都在改**同一个角色**（`$object_guid = 245997`）→ 互相打架 → 表现就是"损坏"。

**已处理**：把 KatTheDev 版移到 `runtime\migoto\_backup_before_v1411\removed_conflicts\`（可随时换回）。
同样处理了另外三组重复：洛茜、佩丽卡、提弗洛斯（顶层那份与 `_endfieldmodcontroller_managed` 那份重复）。

### 2. 庄方宜为什么"没了"→ 它需要游戏真正加载她的模型

lewdlad 版的启用链路（`mod.ini` 第 211–235 行）：

```ini
[Present]
if $object_detected                            ; ← EFMI 检测到 guid=245997 的模型才置 1
    if $mod_enabled
        run = CommandListProcessToggles
    else
        if $mod_id == -1000
            run = CommandListRegisterMod       ; ← 向 EFMI 注册
        endif
    endif
endif

[CommandListRegisterMod]
$\EFMIv1\object_guid = $object_guid
run = CommandList\EFMIv1\RegisterMod
$mod_id = $\EFMIv1\mod_id
if $mod_id >= 0
    $mod_enabled = 1                           ; ← 注册成功才启用
endif
```

而它的 8 个 `[TextureOverride_Component*]` 都带：

```ini
condition = $mod_enabled == 1 && $lod_detected == 0
```

`$lod_detected == 0` 意味着**当前必须是非 LOD 的完整模型**。

**结论**：要走到能看到庄方宜的完整模型的地方（靠近她 / 打开角色界面），才会触发注册与启用。
「诀」「梨诺」等同样机制却出来了，说明当时走到了能看她们的位置。

### 3. 为什么按 Home 召唤不出 ReShade → 宿主被停用了

```
游戏目录 d3d12.dll（ReShade 代理形态）  : False
游戏目录 d3d12.dll.mc_reshade_off       : True   ← 被我改成停用名
```

ReShade 宿主停用 → 按 Home 自然无反应。

**但**：实测 ReShade 代理 + 3DMigoto 同场会**抢 hook 点**：
- ReShade 代理形态 + v1.4.11：24 秒早期退出（连 3DMigoto 都没来得及初始化）
- 桥注入（ReShade 先、EFMI 后）：连加载窗口都不出

所以目前是**「Mod 出来」与「ReShade 可用」二选一**的状态。
