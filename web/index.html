当前路线：三件套（DLSS5 + 第一人称 + 服装 Mod）

  • 唯一 ReShade 底座 = 内置 runtime\dlss5\d3d12.dll（ReShade 6.8.0），里面同时挂着 RenoDX-DLSS5 与 Endfield Enhancer（第一人称） 两个插件。
  • 由 XXMI 在启动游戏时注入两个 DLL：runtime\dlss5\d3d12.dll + runtime\builtin\XXMI\EFMI\d3d11.dll（服装 Mod 引擎）。
  • 同一进程只能有一个 ReShade，所以两个 d3d12.dll 不要同时注入 —— 本程序只注入一个。
  • 启动页的「三件套注入」开关直接改写 XXMI 的注入库：开 = 三件套齐活，关 = 只跑服装 Mod。
  • 外部选择 Mod 库里的 Mod，程序把选中项 staging 到 EFMI\Mods\MC_*（同角色互斥、原始快捷键屏蔽），原库只读。
  • 游戏目录保持干净：不写任何 ReShade/addon，注入全部由 XXMI 完成。

进游戏后

  • 按 Home 打开 ReShade：插件页应同时有 RenoDX-DLSS5 与 Endfield Enhancer。
  • DLSS5 页勾「启用DLSS神经渲染」+「启用超分；风格选电影，总体/结构强度拉满，角色皮肤结构 ≥ 0。
  • Enhancer 的 Camera 页：先开 Camera Controls → First Person = On → Third Person During Combat = Off（打 boss 才不会被踢出第一人称）→ EFMI/XXMI Compatibility = On。
  • 快捷键：F6 神经渲染开关、F11 Mod 显示、, 第一人称、F12 EFMI 帮助。

注意

  • Mod 有 ToS / 账号风险；显卡压力也比单开大（UP 主建议 40 系以上）。
  • 游戏目录里的第三方 proxy（d3dcompiler_47.dll / vulkan-1.dll）属于别的工具（如 SecondaryMotion 摇乳管理器），与本方案无关，但会出现在「检查游戏目录注入」列表里。
